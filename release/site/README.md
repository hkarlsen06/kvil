# Kvil public pages

Static support and privacy pages ready for hosting. `dist/` is authored source with no build step or dependencies. No analytics, external fonts, cookies, forms, or JavaScript. The site follows system appearance using Kvil's bundled artwork.

Run `python3 -m http.server 8765 --bind 127.0.0.1 --directory release/site/dist` from the repository root to preview. Before App Store submission, publish these files to a public HTTPS host and set the verified support/privacy URLs in App Store Connect. Publication has not been performed.
