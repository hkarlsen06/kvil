# Store screenshots

These are unmodified captures of Kvil's production SwiftUI views using fictional schedules and reflections. English and Norwegian iPhone images are 1320 × 2868. Watch images are 410 × 502 in both languages. The purchase review image uses Apple's local StoreKit test catalog at US $3.99.

`manifest.json` records each file, dimensions, and SHA-256. No screenshots have been uploaded. The iPhone images belong to the 6.9-inch display class in App Store Connect. The Watch screenshots are captured on the Ultra 2 simulator. Smaller-phone and 42-mm Watch layout checks are separate QA captures under `build/`.

Apple's current [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) accept these dimensions. Actual upload validation is still required.
