# Bundled artwork

The landscape is Kayvan Mazhar's photograph of Rice Lake, licensed from Unsplash. The original, license link, and credit are in `design/photography/`. One optimized `rice-lake.jpg` in `ios/SharedResources/Assets.xcassets/Landscape.imageset/` supplies every native landscape view and the illustrated widget in both appearances. The main tabs have no decorative photography. About and the purchase sheet use rounded photo frames; onboarding retains its separate transition below the image. The website uses the same exported photograph. Artwork is bundled and works offline. All artwork is free.

Regenerate the shared export on macOS with `sips -Z 2400 -s format jpeg -s formatOptions 80 design/photography/rice-lake-kayvan-mazhar.jpg --out ios/SharedResources/Assets.xcassets/Landscape.imageset/rice-lake.jpg`. Copy that file to the canonical portfolio's `public/kvil/assets/rice-lake.jpg` when refreshing the website. Preserve the original photograph's colors.

The app icon was recreated by hand as SVG on 13 September 2026, preserving the original open ivory arc, sage hills, sun, and forest-green background. `design/artwork/icon.svg` is the editable source, with named background, circle, sun, and hill groups. All artwork in this SVG is vector geometry with simple gradients; it contains no embedded raster images. The full-bleed square leaves the outer icon mask to the platform.

Run `python3 scripts/generate-launch-logo.py` after changing the icon or semantic ink colors to update the transparent light/dark launch logos. These preserve the authored mark and use the shared `Ink` colors for the arc and sun. The native launch screen and initial SwiftUI view both center the same 160-point asset on `Canvas`.

Run `python3 scripts/generate-icon.py` on macOS to derive the transparent `icon-mark.svg` for dark backgrounds, the `icon.png` preview, and the 1024-pixel PNGs in both app targets' asset catalogs. The export uses the built-in Quick Look renderer. Edit `icon.svg`, then regenerate; do not edit its exports independently. The website uses the same vector artwork; its export and deployment instructions are in `release/site/README.md`.

Original raster icon prompt (reference for the vector recreation): Square opaque full-bleed deep muted forest-green field. A warm ivory circular arc with its bottom quarter open and rounded ends, surrounding simple overlapping sage-green hills and a small ivory sun. Generous margins, legible at small sizes, clean restrained shapes. No text, badge, border, phone mockup, or rounded outer corners; the platform applies its mask.
